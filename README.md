# Sinucou: Sinuca e Truco

Jogo Android da GoScripts (Godot 4.3) com sinuca brasileira e truco paulista, online 1x1 e 2x2.

- `jogo/` — projeto Godot (abrir `jogo/project.godot`)
- `servidor/` — servidor de encontro/relay em Node.js (sem dependências), hospedado na Render (`render.yaml`)

A chave de publicação (`*.keystore`) **nunca** vai para o repositório.
